# 🎶🇰🇷 K-ULTURE - Interactive K-Pop Goods Distributor Webpage 

A simple and minimal webpage embracing K-Pop cultures by offering a wide variety of the latest K-Pop albums and discographies as an online K-POP goods distributor, built using advanced HTML elements and CSS.

## ✒️ Project Description 

As a lab assignment from the course Web Development 1, this project is a webpage designed to demonstrate fundamental front-end web development skills. The goal of K-ULTURE is to showcase various K-Pop goods at affordable prices in an attractive and responsive layout using HTML for structure and CSS for styling. The project is deployed on Vercel.

## 💡 Main Features

- A Home Page with a K-POP theme
- A Contact Page with an interactive Customer Contact Form
- Sections highlighting achievements of the store, products and services, and best-selling albums
- Custom fonts, colors, and images
- Features of navigation for header and footer

## 🔧 Technologies Used

- HTML5
- CSS3
- Vercel
